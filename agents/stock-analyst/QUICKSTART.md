# 🚀 快速上手

## 1. 安装依赖

```bash
cd agents/stock-analyst
pip3 install -r requirements.txt
```

## 2. 配置 API Key

```bash
export ANTHROPIC_API_KEY=你的key
```

## 3. 运行分析

### A 股示例

```bash
# 贵州茅台
python3 agent.py 600519

# 五粮液
python3 agent.py 000858

# 宁德时代
python3 agent.py 300750
```

### 美股示例

```bash
# 苹果
python3 agent.py AAPL

# 特斯拉
python3 agent.py TSLA

# 英伟达
python3 agent.py NVDA
```

## 4. 输出说明

分析报告包含以下部分：

1. **今日行情** - 当前价格、涨跌幅、成交量等
2. **技术指标** - MACD、KDJ、RSI、均线、量比
3. **资金分析** - 主力资金流向（A股）
4. **舆情分析** - 新闻情绪判断
5. **综合评分** - 技术面(40%) + 资金面(35%) + 消息面(25%)
6. **明日预测** - 涨跌倾向、概率、支撑/阻力位

## 5. 评分标准

### 综合评分区间

| 评分 | 倾向 | 上涨概率 |
|------|------|----------|
| ≥75 | 强烈看多 | 70% |
| 65-74 | 偏多 | 62% |
| 55-64 | 谨慎偏多 | 55% |
| 45-54 | 中性震荡 | 50% |
| 35-44 | 谨慎偏空 | 40% |
| 25-34 | 偏空 | 35% |
| <25 | 强烈看空 | 25% |

## 6. 注意事项

⚠️ **风险提示**
- 所有分析仅供参考，不构成投资建议
- 股票预测本质是概率分析，无法保证准确
- 免费 API 可能有限流，建议不要频繁调用
- 美股资金流向数据暂不支持

## 7. 常见问题

**Q: 提示"无法连接 Anthropic API"？**
A: 检查网络连接和 API Key 是否正确。

**Q: 提示"请求太频繁被限流"？**
A: 等待几分钟后重试，或更换 API Key。

**Q: 美股数据获取失败？**
A: Yahoo Finance 可能限流，稍后重试。

**Q: 如何使用其他模型？**
A: 使用 `--model` 参数，如 `python3 agent.py 600519 --model claude-sonnet-5`
