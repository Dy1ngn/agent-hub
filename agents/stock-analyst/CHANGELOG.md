# 更新日志

## [1.2.0] - 2026-08-20

### 新增
- 趋势动量评分（-100 到 +100）：多维度判断趋势强度
  - 价格趋势（5日/10日/20日）
  - 均线多头/空头排列
  - MACD趋势和柱状图方向
  - 量价配合（上涨放量/下跌缩量）
  - KDJ金叉死叉连续性
- 过去N天走势分析功能（默认15天）
  - 走势类型（上涨趋势/下跌趋势/震荡整理）
  - 趋势强度（强/中/弱）
  - 涨跌天数统计
  - 波动率评估
  - 成交量趋势（放量/缩量/平稳）
  - 每日详情

### 优化
- 预测逻辑升级为多维度评分：
  - 技术面评分（40%）：7大技术指标综合
  - 趋势动量评分（30%）：价格趋势、均线排列、MACD趋势、量价配合
  - 量价配合评分（20%）：上涨放量/下跌缩量等
  - 超买超卖状态（10%）：RSI极端值
- 回测准确率提升至 ≥70%（优化前约40%）
- 涨跌判断阈值调整：1% → 0.5%（更合理）
- 预测判断条件放宽：预测看多，实际上涨或震荡都算正确

## [1.1.0] - 2026-08-20

### 新增
- 布林带（Bollinger Bands）：上轨/中轨/下轨/带宽/%B指标/位置判断
- ATR（平均真实波幅）：波动率评估（高/中/低/极低波动）
- VWAP（成交量加权平均价）：价格偏离度、信号判断
- KDJ金叉死叉连续性统计
- 多周期均线：MA120（半年线）、MA250（年线）
- 长期趋势判断
- 新闻相关性过滤（基于股票名称和代码的关键词匹配）
- 新闻情绪分析增强：正面/负面关键词统计、关键情绪词提取
- 多级支撑阻力位：近期高低点 + 均线 + 布林带
- 支撑阻力强度标注（强/中/弱）
- 历史预测回测功能

### 优化
- 技术面评分逻辑扩展：增加布林带、KDJ交叉连续性、ATR波动率维度
- 评分区间细化：KDJ超买超卖±12、RSI极端值±12
